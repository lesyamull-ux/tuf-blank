# ТЮФ — рабочий бланк

Одностраничный бланк для теста юмористических фраз. Без сервера и без сборки: один `index.html`.

- Клиент обозначается **только номером** (поле принимает лишь цифры) — персональные данные не вводятся и не хранятся.
- Данные лежат в `localStorage` браузера (на устройстве, никуда не отправляются).
- Вкладка **Архив**: все сессии, скачивание в CSV (Excel) и резервная копия в JSON, загрузка копии обратно.
